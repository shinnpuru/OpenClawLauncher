模型与 LlamaCPP

插件与备份

插件安装/卸载、推荐插件一键安装；zip 备份与恢复后自动尝试重装依赖。

快速开始

与 README 保持一致：下载 → 安装 → 进入快速上手面板

1) 下载与安装

  1. 进入 Releases 下载适配系统的安装包（macOS / Windows）
  2. macOS 将 .app 放入"应用程序"；Windows 直接运行 .exe
  3. 首次启动建议进入"快速上手"面板

2) 初始化配置

  1. 先确认 Node.js / OpenClaw 依赖状态，然后创建实例
  2. 在"LlamaCPP + 模型切换"完成本地或在线模型配置
  3. 配置频道后运行实例，在日志与备份面板做运行保障
