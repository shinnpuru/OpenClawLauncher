快速开始

三步，开始你的 OpenClaw。

阅读完整指南 ↗
  1. 01

    下载并打开

    选择适合系统的压缩包并解压。macOS 将应用移入“应用程序”；Windows 打开启动器。

  2. 02

    一键安装并启动

    进入“快速上手”，点击一键按钮。启动器会准备所需运行时，创建默认实例并启动。

  3. 03

    连接模型与频道

    填写模型服务配置，连接需要的聊天频道，再打开 WebUI，开始使用你的 OpenClaw。

常见问题

再了解一点。

OpenClaw Launcher 和 OpenClaw 有什么区别？+

OpenClaw 是 AI 助手项目；OpenClaw Launcher 是帮助你安装、配置和运行它的桌面应用。启动器提供图形界面，把运行时准备、模型配置和日常管理集中到一起。了解 OpenClaw ↗

需要提前安装 Python 或 Node.js 吗？+

使用发布版安装包，无需先准备 Python 开发环境。“快速上手”会安装所需 Node.js 和 OpenClaw 运行时。首次初始化需要网络连接。

可以使用本地模型吗？+

可以。你可以连接 Ollama，或在 LlamaCPP 面板中加载 GGUF 模型并启动本地服务。本地推理需要与你的模型相匹配的内存和硬件；也可以选择在线模型提供商。

软件免费吗？模型服务也免费吗？+

启动器以 MIT 协议免费开源。在线模型提供商可能按各自规则收取 API 费用；使用本地模型则需要自己准备模型文件和运行硬件。
